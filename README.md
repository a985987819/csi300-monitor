# 流通基金概览 —— 指数基金 + 债券基金筛选分析 + 市场全景

> 仓库：https://github.com/a985987819/csi300-monitor

按截图复刻的基金筛选大屏，**数据实时调取天天基金网公开接口**，无需预生成、无需手工更新。
顶栏新增「市场」板块：情绪温度 / 板块资金流持续性 / 题材振幅 / 年度涨跌 / 风险性价比 / 热点题材桑基轮动（东方财富公开行情接口，JSONP 直连）。
既可本地实时运行，也可作为纯静态站点一键部署到 **GitHub Pages**（见下文）。

## 市场全景（市场板块）

- **大盘指数**：上证指数 / 深证成指 / 创业板指 / 科创50 × 今日 · 成交额 · 近5日 · 近20日 · 上涨家数占比（广度红绿条）+ 走势迷你图
- **情绪温度**（涨停/跌停/炸板池，push2ex）：涨停家数、跌停家数、最高连板、连板家数、炸板率——判断封板强弱与分歧度
- **今日盘面**：主力净流入 TOP10 / 净流出 TOP10（含 **5日累计净额**、**连续净流入/流出天数**、**价量资金背离角标**）/
  振幅最大 TOP10（含 **收盘位置**，区分冲高回落与放量收高位）；行业板块+题材混排，悬浮可见净占比与领涨股
- **年度纵览**：今年来涨幅/跌幅最大 TOP10（口径起止日期显式标注，盘中自动剔除今日未收盘贡献）
- **板块风险性价比**（与基金筛选同口径）：年化波动率、近20日最大回撤、收益/波动比、收益/回撤比（简化卡玛）——回答「热点值得用基金承接还是只适合短线」
- **热点题材动态**：近20日 → 近5日 → 今日 的题材轮动**桑基图**（涨/跌各一张，题材唯一键=板块代码）+ 四张窗口累计涨跌榜（近5日/近20日 × 涨/跌，连乘口径）
- **个股动向**（观察池）：三一重工 / 柳工 / 安道麦A / 中原内配 / 美的集团 —— 对比表（收盘/今日/近5日/近20日涨跌 + 主力净额/连续天数/5日与20日累计净额/资金动向红绿柱）+ 近20日归一化累计涨跌五线对比图（个股日K含成交额，主源失败降级腾讯fqkline）
- **大盘云图**：双层 squarified treemap——行业板块按总流通市值分块，块内个股按流通市值定大小、当日涨跌幅定颜色（红涨绿跌9档色带，灰=停牌）；大块显示名称+涨跌幅，悬浮看明细，点击打开东财个股页；仅行业板块（概念板块个股跨板块重叠会重复计价）；实时快照（盘中=盘中涨跌，收盘后=当日收盘），成分按基准日缓存
- **事件与风险雷达**（datacenter-web）：龙虎榜 净买入/净卖出 TOP8（近3个交易日，含上榜原因与次日表现——事后验证）、未来30天解禁 TOP10（按解禁市值，类型标注）、最新业绩预告（近3日公告，预增红/预减绿+净利区间+变动幅度）；用于提前排雷而非收盘后追热点
- **待接入（P0剩余，源已定位）**：指数PE/PB十年分位与ERP（1/PE−10Y国债）——datacenter 无指数估值报告、chinamoney 10Y 接口参数待解；策略为页面每日自建估值快照积累分位（文档建议口径）；两融/ETF份额/减持明细待报告名核实
- **基准日规则**：收盘后（15:05 起）统计当日；盘中 / 午休 / 盘前 / 节假日自动统计最近一个已收盘交易日（以指数日K为准，节假日安全）
- **字段口径**（已与日K逐位交叉验证）：f3 今日 · f7 振幅 · f109 近5日 · f160 近10日 · f24 近60日 · f25 年初至今 · f62 主力净流入 · f184 净占比 · f164 近5日主力净流入；
  fflow 日K：f52 主力净额 / f57 净占比（f52=大单+超大单 恒等式验证）；涨停池：tc 涨停数 / lbc 连板数 / zbc 炸板次数 / hybk 行业板块
  基准日窗口 = 含今日窗口 ÷ (1+今日涨跌幅)，代数精确；近20日无现成字段，按各窗口榜单极值候选池逐板块拉日K精确计算
- **数据源与降级**（免费公共接口，无登录）：东财 push2/push2his（主源）→ 指数快照/日K失败时自动切换**腾讯行情** qt.gtimg.cn / web.ifzq.gtimg.cn 并标注"腾讯降级源"；push2ex 情绪池独立主机
  东财按出口 IP 对 push2 集群限流（突发即连接重置，通常十几分钟至一小时自愈，期间基金页不受影响）
- **请求纪律**：全量约 7（清单+广度+情绪）+ ~300（板块候选日K）+ ~200（板块资金流日K）个请求/基准日，150ms 节奏 + 镜像主机轮换 + 退避重试 + 部分失败容忍；**按基准日缓存，当日重访秒开**

## 启动（一条命令）

```bash
cd csi300-monitor
python server.py          # 或双击 启动.bat
# 浏览器打开 http://127.0.0.1:8437/
```

`server.py` 仅用 Python 标准库（无第三方依赖），做两件事：
1. 静态托管页面；
2. `/api/east` 本地中继——天天基金的 F10 接口校验 Referer 必须是 `*.eastmoney.com`，浏览器跨域直接读会被拦，
   中继负责补足 Referer/UA 后转发（含 60 秒短缓存与并发保护）。

> 也可直接双击 `index.html` 离线打开（自动降级为 `data/data.js` 离线快照，仅沪深300），但实时能力需要 server.py。

## 部署到 GitHub Pages（纯静态，无需服务器）

1. 把本目录推送到 GitHub 仓库（`data/all.json` 已内置全部页签快照）
2. 仓库 **Settings → Pages → Source 选 `main` 分支根目录**（或直接访问 `https://<user>.github.io/<repo>/`）
3. 页面检测到无 `/api/health` 中继时自动进入「快照模式」：读取 `data/all.json` 一次，全部功能（筛选/排序/搜索/自选/对比/导出）照常可用
4. 数据更新：仓库自带 GitHub Action（`.github/workflows/update-data.yml`）**每月 1 日自动采集全部 16 个页签**并提交 `data/all.json`；也可在 Actions 页手动触发

> 快照由 `tools/fetch_data.py --all` 生成（增量合并各页签），本地也可随时重跑：
> `python tools/fetch_data.py --all --workers 8`，或只更新单页签 `python tools/fetch_data.py --universe hs300`。

## 数据如何"实时"

| 数据 | 通道 | 说明 |
|---|---|---|
| 基金清单/类型/拼音 | `fundcode_search.js`（script 直连） | 全市场 2.8 万只里筛出沪深300 |
| 阶段涨幅/年度涨幅/持有人结构 | `FundArchivesDatas.aspx`（经中继） | 天天基金官方口径 |
| 费率/概况/特色数据/资产配置 | F10 页面 `jbgk/tsdata/zcpz`（经中继） | 浏览器内解析 |
| 2015-2017 年度涨幅 | `pingzhongdata`（script 直连） | 官方日增长率复权链计算 |
| 沪深300指数基准行 | `push2his` K线接口（官方支持 JSONP/CORS） | 指数本身口径 |

- 首次加载约 1-2 分钟（带进度条，2200+ 请求，指数/详情并发受控 + 4 次退避重试 + 失败补扫）
- **按月同步**：本地记录每个页签的最后同步时间，**间隔超过 1 个月才会重新走接口**；期间打开直接读本地缓存秒出
  （完整记录在同步期内视为新鲜，残缺记录仍只保留 5 分钟便于自动补齐）
- 完整记录缓存 6 小时 TTL 兜底；「⟳ 刷新数据」按钮强制重新拉取
- 残缺记录（个别请求失败）只缓存 5 分钟，下次打开自动补齐
- 断网/无中继时自动降级为离线快照 `data/data.js`（顶栏会亮黄色"离线数据"）；
  部署态（GitHub Pages）自动读取 `data/all.json` 全页签快照（"快照数据"）

## 功能清单

- **表头两级分组**：基本信息 / 规模 / 成立信息 / 收益表现 / 年度涨幅 / 阶段涨幅 / 费率 / 资产配置 / 持有人结构 / 风险指标 / 跟踪与基准
- **分组式列勾选**：按组展示、点击组名整组开关、勾选状态本地保存
- **每个表头都可筛选**（漏斗图标）：数值列支持「前 10 项 / 高于平均 / 低于平均 / ≥ ≤ 范围」，
  显示「平均 X · N 个有效值」与命中数；日期列支持 ≥≤ 区间；文本列支持包含关键字模糊匹配
  ——多列筛选自动叠加（AND），可与排序、关键词搜索并用
- **关键词模糊匹配**：简称 / 代码 / 经理 / 管理人 / 类型，支持拼音缩写（如 `hs300etflja`）
- **公司下拉筛选**：公司图例改为可搜索下拉框，支持公司名与**拼音首字母**模糊搜索（如 `yfd` 易方达）
- **我的自选基金**：行首星标收藏，顶部「我的自选」页签聚合查看（跨页签、本地持久化）
- **基金对比**：勾选 2-4 只基金 → 「开始对比」弹窗并排展示全部指标 + 业绩走势叠加图（含基准虚线）
- **点击表头排序**：降序 → 升序 → 恢复默认；缺失值沉底；粘性列（序号/代码/简称横向固定，表头纵向固定）
- **导出当前页**（CSV，UTF-8 BOM）与 **导出 Excel**（.xls）——所见即所得，含当前筛选与可见列
- **设置**：深浅主题、紧凑行高、涨跌着色（正红负绿）、优选高亮开关、本地缓存开关
- 开市/休市状态（北京时间自动判断）+ 实时服务器时钟

## 优秀指标高亮（市场通用口径）

绿色高亮不再只取前 15%，而是**对达到"市场常见优秀标准"的数据全部高亮**（可叠加多只）：

| 指标 | 优秀阈值 | 依据 |
|---|---|---|
| 夏普比率 / 卡玛比率 | ≥ 1 | 主流基金评价平台通用及格线 |
| 最大回撤（近1年/近3年）| ≤ 10% | 波动控制良好的常见界定 |
| 管理费率（合计费率）| ≤ 0.5% | 低费率指数产品主流水平 |
| 规模 | ≥ 2 亿 | 清盘风险线之上 |
| 经理任职年限 | ≥ 3 年 | 经历完整牛熊周期的门槛 |
| 同类排名 | 前 20% | 常见"四分位"优秀档 |

- 无绝对阈值的方向性指标（阶段涨幅等）回退为**列表前 25% 分位**高亮（P75/P25）
- 同一单元格若为全表最优则金色优先；筛选/排序变化后自动重算；设置页可关闭

- **微交互**：筛选弹窗弹入动画、表体淡入、行悬停过渡、美化滚动条；排序/筛选/搜索变化自动回到表格顶部

## 数据口径

| 项目 | 口径 |
|---|---|
| 阶段涨幅 / 年度涨幅(2018-2025) | 天天基金官方（复权）口径 |
| 年度涨幅(2015-2017) | 按官方日增长率复权链计算（与原版工具逐位一致，如 510300: 7.09%/-9.61%/23.14%） |
| 成立来平均年化 | (1+总涨幅)^(365.25/成立天数) − 1 |
| 总规模(亿) | 同一基金各类份额净资产合计 |
| 单支规模(亿) | 该份额最新净资产（报告期见"报告期"列） |
| 指数基准行（首行） | 各页签对应指数本身口径：A股日K + 美股日K（push2his），年度涨幅/阶段涨幅由K线计算 |
| 000300 沪深300指数 | 原基金已清盘、代码复用，故作为指数基准行呈现 |
